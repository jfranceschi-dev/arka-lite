# 06 · Uso y operación

Empiece por un solo camino de ejecución:

1. [Primera ejecución y depuración con Maven o IntelliJ](01-ejecucion-y-depuracion.md) si va a cambiar código Java.
2. [Docker y Docker Compose](02-docker-y-compose.md) para iniciar los dos servicios con un comando.
3. [Imágenes, etiquetas y puertos](03-imagenes-etiquetas-y-puertos.md) para cambiar la configuración local con criterio.
4. [Kubernetes local con Docker Desktop y `kind`](04-kubernetes-local.md) para desplegar los manifiestos del proyecto; [limpieza](05-kubernetes-limpieza.md) al terminar.

Opciones adicionales: [explorar Kubernetes con K9s](06-k9s.md) y [añadir HTTPS y certificados](07-https-y-certificados.md). Ambas son optativas y no forman parte de la configuración actual.

El esquema de HTTPS tiene una [fuente Mermaid independiente](08-flujo-https.mmd) y se representa en la guía de certificados.

Consulte la [referencia rápida de comandos](../03-comandos/01-comandos.md) si ya conoce el procedimiento.
