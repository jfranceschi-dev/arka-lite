# K9s para explorar Kubernetes (opcional)

[K9s](https://k9scli.io/topics/install/) es una interfaz de terminal para inspeccionar recursos del clúster. No sustituye `kubectl` ni crea el clúster. Instale una versión para Windows desde su página oficial o use uno de los gestores de paquetes allí indicados. Antes de abrirlo:

```powershell
kubectl config current-context
kubectl get nodes
k9s
```

El contexto debe ser `docker-desktop`. Dentro de K9s, escriba `:pods`, `:deploy` o `:svc` para ver pods, Deployments o Services; seleccione un recurso y pulse `l` para registros, `d` para su descripción y `?` para la ayuda de atajos de su versión. Use `Esc` para volver y `:quit` para salir. Puede cambiar el namespace desde la interfaz; los recursos de esta guía se crean en `default` si no configuró otro.

Para investigar ARKA-Lite: abra `:pods`, compruebe que ambos estén listos, inspeccione el pod de solicitudes y sus logs, después el de notificaciones. Para cambios reproducibles en el equipo, edite los manifiestos `k8s/` y aplíquelos con `kubectl` según la [guía de Kubernetes](04-kubernetes-local.md), de modo que lo observado en K9s coincida con el repositorio. Tenga cuidado con los atajos de eliminación o edición: actúan sobre el clúster seleccionado.
